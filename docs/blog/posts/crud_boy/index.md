# A Little CRUD Boy 卖苦力的小男孩

> 标题 neta 了丹麦童话《卖火柴的小女孩》。

以前我晚上闲着没事，总是喜欢去出租屋附近的糖水老店去点一杯。倒不是因为有多喜欢喝糖水，只是我不是广东人，第一次来心心念念的广东打工，而且只干半年就走，我觉得机会难得，应该趁机多吃些当地特色菜。

<!-- more -->

但是今天晚上我对着糖水店的菜单看了又看，觉得刚来广东的新奇劲过了之后，糖水能带来的情绪价值其实并不值它的价格。于是我去蜜雪冰城点了一杯桑葚莓莓。写了一天代码，晚上喝到这种看颜色就觉得花青素很丰富的饮料，觉得眼睛一下子就不酸涩了。

我小时候听大人说，温州土地贫瘠，适合种桑葚。其实并不是这样，如果说温州适合的话，那么其他所有土地比温州肥沃的地方都特别适合，但大家不会说其他城市适合种桑葚。说温州适合种桑葚，只不过是说生活在温州这片穷山恶水的人种桑葚比种其他作物更不容易饿死而已。就像我在广东写代码，并不是因为我这个自称喜欢语言学的精神文科生生来就特别适合写代码，只不过我这个笨逼做这一行比做其他行业更不容易饿死。

我要牢牢记住这个结论，以后生活会考。
